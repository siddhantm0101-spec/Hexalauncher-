# HEXA Launcher 2.0

A refreshed native Android launcher project with a photo-backed home screen.

## What's improved
- Choose a photo from Gallery and use it as the HEXA home-screen wallpaper.
- Wallpaper URI is persisted so it remains after closing/reopening the launcher.
- Transparent launcher surface and dim overlay keep home text readable over photos.
- Fixed the hero card line break (it now displays on two lines).
- Java and Kotlin compile targets are both set to JVM 17.
- Existing app drawer, search, favourites, hidden apps, accent themes, grid settings and edge panel retained.

## Build APK
1. Upload all files and folders in this ZIP to the root of your GitHub repository.
2. Open Actions > Build HEXA Launcher APK > Run workflow.
3. Download artifact `HEXA-Launcher-2.0-debug`.
4. Extract `app-debug.apk` and install it on your phone.

Package: `com.hexa.launcher`
Version: `2.0`

This is a third-party launcher, not a replacement Android OS. It cannot replace Samsung system UI or system-level One UI features.
